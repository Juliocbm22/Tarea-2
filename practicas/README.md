# Prácticas del curso

Coloca aquí una carpeta por cada práctica realizada en clase, con sus archivos
(Dockerfile, código, docker-compose.yml, etc.). Ejemplo:

```
practicas/
├── practica-01-hola-docker/
├── practica-02-nginx-volumen/
└── practica-03-compose/
```

Cada carpeta debe poder reproducirse con sus propios archivos. Agrega un
`README.md` corto en cada una con los comandos usados (build, run, etc.).
